# Product Roadmap

IdeaByHuman is evolving in three phases. This roadmap outlines our vision for the platform.

## Phase 1: Foundation & Launch (Current)

Build a solid, user-friendly platform for discovering and sharing AI-built projects.

### Core Platform
- [ ] Project gallery & discovery
- [ ] Advanced search & filtering
- [ ] Project detail pages
- [ ] User profiles & portfolios

### Submission & Review
- [ ] Submission form with story sections
- [ ] Admin review dashboard
- [ ] Email notifications for creators
- [ ] Public & draft project states

### User Features
- [ ] Creator authentication (magic links)
- [ ] Favorite/save projects
- [ ] User profiles
- [ ] Project comments & feedback

### Content
- [ ] 7 initial categories
- [ ] Tagging system
- [ ] Featured projects homepage section
- [ ] Project search & discovery

### Technical
- [ ] Supabase authentication
- [ ] Cloudflare R2 media storage
- [ ] API routes for submissions
- [ ] Database schema & migrations

## Phase 2: Community & Engagement (Q2 2025)

Build community features that make IdeaByHuman a hub for AI builders.

### Community Features
- [ ] Project comments & discussions
- [ ] Creator-to-creator messaging
- [ ] Public profiles with project history
- [ ] User reputation system
- [ ] Activity feed

### Creator Tools
- [ ] Creator dashboard with analytics
- [ ] Project edit & update capability
- [ ] Draft/publish workflow
- [ ] Project view tracking
- [ ] Response to feedback

### Engagement
- [ ] Weekly feature email digest
- [ ] Project voting & rankings
- [ ] Trending projects section
- [ ] Creator spotlights & interviews
- [ ] Community guidelines

### Admin & Moderation
- [ ] User reporting system
- [ ] Content moderation tools
- [ ] Community guidelines enforcement
- [ ] User role management

### Technical
- [ ] Email digest service
- [ ] Real-time notifications
- [ ] Comment moderation tools
- [ ] Analytics dashboard

## Immediate Priorities (Next 30 Days)

1. **Launch**: Get core platform live and stable
2. **Content**: Curate initial projects to showcase
3. **Feedback**: Gather user feedback from early adopters
4. **Polish**: Refine UX based on user testing
5. **Promote**: Begin building community and awareness

## Key Success Metrics

We'll measure success by:

### Engagement
- Monthly active users
- Project submissions
- Community interactions
- Return visitor rate

### Quality
- Approval rate of submissions
- User satisfaction (feedback score)
- Project quality ratings
- Creator retention

### Growth
- Month-over-month user growth
- Creator growth
- Project additions
- Community engagement

---

## How We Decide What's Next

This roadmap is not set in stone. We adjust based on:

- **User feedback**: What do creators and browsers actually want?
- **Usage patterns**: What features do people actually use?
- **Feasibility**: What can we build with our team?
- **Impact**: What has the biggest benefit for effort?
- **Community**: What does the community ask for?

The team reviews this roadmap monthly and adjusts priorities based on learning and feedback.
